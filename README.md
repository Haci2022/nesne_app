 # 👁️ YOLOv8 Nesne Tespiti ve Görüntü İşleme Projesi

Bu proje, *YOLOv8* yapay zeka modelini kullanarak görüntü işleme, nesne tespiti ve ilgili uygulama akışlarını gerçekleştirmek amacıyla geliştirilmiştir.

---

## 📂 Proje Dosya Yapısı

* *yolov8n.pt*: Nesne tespiti için kullanılan önceden eğitilmiş YOLOv8 nano model ağırlıkları.
* *ana.py*: Projenin ana çalıştırma ve entegrasyon betiği.
* *uygulama.py & uygulama1.py*: Arayüz/görüntü işleme mantığını ve test senaryolarını içeren Python dosyaları.
* *sertifika.py*: Sertifika/doğrulama veya ilgili yardımcı işlemleri yürüten modül.

---
